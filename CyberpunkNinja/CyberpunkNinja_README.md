# Cyberpunk Ninja

## Instructions
A ninja action platformer set in a futuristic sci-fi city. You play as Hotaru, a young woman who wakes in the slums with no memories and a ghost in her head. Fight your way up to the Kanshi Spire.

Click the green flag to begin. In the menu screen, you can use the bottom-most button to see the list of controls. You'll also be introduced to the mechanics gradually as you play the game. If the game is too hard, go to the "Options" screen (either through the starting menu or the pause menu) and dial down the difficulty.

BASIC CONTROLS:
- 'A' to run left, 'D' to run right, 'W' to jump
- Left click: Attack
- Space: Phase Step (dash/dodge)
- 'S': Press briefly to deflect or hold to block
- 'P': Pause game

## Notes and Credits
An RPG platformer drawing inspiration from Celeste for the platforming and Sekiro for the combat mechanics. Absolutely filled to the brim with tropes from the cyberpunk genre.
