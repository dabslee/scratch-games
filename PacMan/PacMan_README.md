# PacMan

## Instructions
- Click the green flag to start.
- Use the arrow keys or WASD to steer Pac-Man around the maze.
- Eat all the dots to clear the level. Grab fruits that appear for bonus points.
- If a ghost catches you, you lose a life. Eat a big flashing power pellet to turn the ghosts blue for a few seconds, during which you can eat them for bonus points. When they start flashing white, they're about to turn back!
